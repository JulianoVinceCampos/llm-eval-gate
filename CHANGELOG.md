# Changelog

Todas as mudanças relevantes deste projeto ficam registradas aqui. O formato segue o
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) e as versões seguem o
[Semantic Versioning](https://semver.org/spec/v2.0.0.html). As entradas são geradas pelo
release-please a partir dos Conventional Commits, então cada mensagem de commit é a nota de
release.
