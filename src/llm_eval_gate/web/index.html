Por que este gate existe

Todo mundo publica wrapper de LLM. Quase ninguém publica a régua. Este painel mostra a régua funcionando: cada candidato é comparado caso a caso contra uma referência aceita, e o veredito tem três estados. Passa quando o intervalo exclui uma perda maior que a margem, reprova quando exclui que a perda caiba nela, e fica inconclusivo quando os dados não dizem.

A régua também é medida: a calibração simula milhares de trocas de modelo com efeito conhecido e publica quantas vezes o gate erra. O intervalo que decide é o score de Tango, escolhido porque o bootstrap percentil, muito usado em avaliação, aprova regressão que não enxerga quando há poucos casos.

O baseline é determinístico e vem antes de qualquer IA: as 31 regras do postmortem-miner com um classificador por assinatura. O LLM só entra medido contra ele.

Tudo aqui é sintético e gerado por código versionado. Nada vem de sistema, cliente ou colega real.
